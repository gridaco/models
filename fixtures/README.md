# Model test fixtures

Models includes reusable media fixtures for testing AI model modalities and perception. Use them to check whether a model accepts a type of input and whether it correctly interprets the content.

We use real media with recognizable, meaningful content. Each fixture documents what a model should recognize, the relevant file properties, and the source and license.

- [Speech audio](./audio/speech/) includes a WAV recording and its reference transcript for testing speech recognition.
